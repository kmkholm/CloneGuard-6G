# GNS3 screenshot for Figure 3(b)

While a 4-site run of the campaign is active (project_ids.json holds the project id):

1. Open http://localhost:3080/static/web-ui/server/1/project/<project_id> in the built-in browser (login admin / password from %APPDATA%\GNS3\2.2\gns3_server.ini).
2. Fit the topology (toolbar "Zoom to fit"), hide the console pane, take a screenshot and save it as figures/gns3_shot.png.
3. Re-run figure_src/fig_topology.py.
